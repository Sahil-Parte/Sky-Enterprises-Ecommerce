# Sky Enterprises Sales Dashboard

An interactive sales dashboard created for Sky Enterprises to analyses sales performance, profit, products, categories, and monthly trends using Advanced Excel.

## Tools Used
- Microsoft Excel(Advance)

## Key KPIs
- Total Sales
- Total Orders
- Total Profit
- Profit Margin
- Average Order Value
- Total Quantity
- Sales Growth

## Key Analysis
- Month-wise sales analysis
- Category-wise sales
- Top products by sales
- Profit analysis
- Best and lowest sales months
- Sales and profit performance

## Key Insights
- Identified the highest-selling products and categories.
- Analysed monthly sales performance.
- Compared sales and profit performance.
- Identified the best and lowest-performing sales months.
